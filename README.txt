27 RAZONES PARA AMARTE — PARA HABIBI ♡
============================================

CONTENIDO
- index.html: página principal con enlaces a las 27 razones.
- razon-01.html a razon-27.html: una página individual con reproductor real de audio por razón.
- styles.css: diseño romántico en crema, rosa y dorado.
- generar-codigos.html y qr-generator.js: generador de 27 QR individuales.
- audio/: coloca aquí los 27 archivos de audio de Voice Memos.

NOMBRES EXACTOS DE LOS AUDIOS
Dentro de la carpeta audio, coloca los archivos con estos nombres:
  razon_para_amarte (1).m4a
  razon_para_amarte (2).m4a
  ...
  razon_para_amarte (27).m4a

Cada página ya apunta al archivo correcto. Por ejemplo, razon-01.html carga
 audio/razon_para_amarte (1).m4a, y razon-27.html carga
 audio/razon_para_amarte (27).m4a.

En Windows, si las extensiones están ocultas, activa Explorador de archivos > Ver > Mostrar > Extensiones de nombre de archivo. Comprueba que los archivos no terminen accidentalmente en .m4a.m4a.

CÓMO PUBLICAR GRATIS CON GITHUB PAGES
1. Extrae este ZIP en tu computadora.
2. Copia las 27 grabaciones M4A dentro de la carpeta audio, conservando los nombres exactos anteriores.
3. Crea un repositorio de GitHub para la web y sube TODOS los archivos y carpetas de este paquete (incluida audio).
4. En GitHub, abre Settings > Pages y habilita el despliegue desde la rama principal (root). Espera hasta que GitHub muestre la URL publicada.
5. Abre la URL publicada y prueba algunas páginas y audios.
6. Abre /generar-codigos.html en la web publicada. Pega la URL base de la web (debe terminar en /) y pulsa “Crear los 27 QR”.
7. Descarga los códigos PNG uno por uno o usa “Imprimir hoja de QR”. Escanea algunos códigos con un teléfono antes de imprimirlos todos.

IMPORTANTE SOBRE PRIVACIDAD
GitHub Pages es hosting público. Las personas que obtengan los enlaces pueden acceder a las páginas; por eso, no publiques grabaciones que quieras mantener privadas. Para escuchar, el iPhone puede requerir que Habibi toque el botón de reproducción debido a las restricciones de reproducción automática de los navegadores.

El generador de QR usa una pequeña librería externa desde cdnjs; necesitará conexión a internet al crear los códigos.
